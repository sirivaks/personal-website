Ideas I keep coming back to

A feature request is rarely the problem.

People ask for a button. Underneath is usually a broken workflow, missing context, or a job they can’t get done.

What makes an AI product actually useful?

Not the model. Whether it changes a real step in someone’s day — and whether you can tell when it’s wrong.

When should a product use an agent?

When the work is multi-step, messy, and the user shouldn’t have to babysit every click. Not because agents are trendy.

Prototype vs. product.

A prototype proves it can work. A product survives the boring parts: edge cases, trust, evals, and “what if this is wrong?”

From engineering to product.

I used to start with the system. Now I start with the person, then go back to the system with better questions.

Better decisions start with better questions.

Roadmaps full of answers are easy. The work is naming the question that’s worth the next quarter.
